# java-lotto-precourse

## 기능 요구사항

1. **로또 번호 규칙**
    - 1~45 사이의 숫자로 구성
    - 1장의 로또는 중복 없는 6개의 숫자로 이루어짐

2. **당첨 번호 추첨**
    - 6개의 일반 번호 + 1개의 보너스 번호

3. **구매 및 발행**
    - 로또 1장의 가격: 1,000원
    - 사용자가 입력한 금액에 맞춰 발행 수 계산
    - 발행한 로또 번호는 오름차순으로 출력

4. **당첨 기준 및 상금**
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원

5. **결과 출력**
    - 사용자가 구매한 로또와 당첨 번호를 비교해 당첨 내역 계산
    - 총 수익률을 소수점 둘째 자리에서 반올림하여 표시

6. **예외 처리**
    - 잘못된 입력 시 `IllegalArgumentException` 발생
    - 메시지는 `[ERROR]`로 시작
    - 입력 오류 발생 시 해당 부분부터 재입력
